# ``GrateFace``

Create a Photos watch face from new artwork and a foreground mask.

@Options {
    @TopicsVisualStyle(detailedGrid)

## Overview

GrateFace includes a neutral single-photo Photos-face seed. It replaces the seed's images, can omit depth occlusion or use a prepared grayscale mask, and returns a new `.watchface` file URL. Import into Watch is a separate, platform-controlled step.
